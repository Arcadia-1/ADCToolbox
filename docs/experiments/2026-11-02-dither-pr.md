# Standalone Dither PR validation

The PR targets upstream `main` at `cd72061`. It contains six example entry
points, local helpers, tests, packaged guides and physical model derivations.
Public calibration APIs and existing library numerical models are unchanged.
The only Python edit outside examples/tests/audit scripts is a docstring blank
line required for the strict Sphinx build.

Detailed historical results are in the commit-pinned
[evidence archive](dither-results.md#detailed-evidence-archive), with a compact
results table retained here. Neither the algorithm nor the error model changes
when moving those outputs out of the PR.

## Checks

Run from `python/`, using fresh output directories:

```powershell
uv run --extra docs --with pytest --with numba pytest tests/unit/test_dither_background_example.py tests/unit/test_dither_mechanisms.py tests/unit/test_hdc_fixed.py tests/unit/test_hdc_small_signal.py tests/unit/test_hdc_correlation.py tests/unit/test_joint_dither.py tests/unit/test_joint_dither_convergence.py tests/unit/test_pn_architectures.py -q
uv run --no-sync --extra docs sphinx-build -b html -W --keep-going docs/source <new-docs-output>
uv build --out-dir <new-dist-output>
```

From the repository root:

```powershell
python docs/experiments/check_hdc_model_basis_20261102.py --output <new-model-audit.json>
python docs/experiments/check_hdc_physical_equations_20261102.py --output <new-physical-audit.json>
```
