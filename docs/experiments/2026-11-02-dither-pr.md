# Standalone Dither PR validation

The PR targets upstream `main` at `cd72061`. It contains six example entry
points, local helpers, tests, packaged guides and physical model derivations,
and adds the public `DitherGainTracker`, `apply_dither_gain` and
`DitherHDCTracker` APIs in `adctoolbox.calibration.dither`. `DitherHDCTracker`
and the HDC examples share `calibration/_dither_hdc.py`; the optional `accel`
extra installs Numba for its per-sample loop. Existing library numerical
models are unchanged; the only other library edit is a docstring blank line
required for the strict Sphinx build.

Detailed historical results are in the commit-pinned
[evidence archive](dither-results.md#detailed-evidence-archive), with a compact
results table retained here. Neither the algorithm nor the error model changes
when moving those outputs out of the PR.

## Public API review revision

This revision changes the public API, not the example numerics.
`DitherHDCTracker` holds only an unobservable or out-of-range DAC mismatch
estimate, so constant role tags no longer block gain, cubic and memory
updates; `estimate_memory` and `estimate_dac_mismatch` switch these
extensions off. The public HDC defaults are floating arithmetic and
2^24-sample windows. `DitherGainTracker` requires explicit probe amplitude,
initial gain, backend bits and gain bounds, and adds `process`.

With Python 3.13.1 on Windows, `tests/unit` and the skill example tests passed
without Numba (1047 passed, 1 skipped, 1 xfailed), and the targeted command
above passed with it (153 passed, 1 skipped). Strict English and zh_CN Sphinx
builds and wheel/sdist builds passed; the wheel declares the `accel` extra.
Reduced runs of `exp_cal08_hdc_fixed.py` (2^22 samples, 2^18 windows, seed 101,
sine), `hdc_small_signal.py` (seed 111, 2^20 training and test samples, 2^18
and 2^16 windows), `hdc_fixed_controls.py` and `exp_cal01_dither_background.py`
(64 blocks of 2048 samples, constant and step gain) gave CSV and JSON outputs
identical to `fe19fb5`, apart from timings, source hashes and the new
`delta_held` event field. In the small-signal run that field marks windows
whose stage codes stay at zero, where the mismatch was already unobservable
and held.
